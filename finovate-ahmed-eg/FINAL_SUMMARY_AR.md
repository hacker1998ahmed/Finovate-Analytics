## 🏢 الأنظمة الفرعية المكتملة (18 نظام)

### 1. الفاتورة الإلكترونية المصرية (ETA) ✅
- التكامل الكامل مع API هيئة الضرائب
- OAuth2 Authentication (Access/Refresh Tokens)
- Submit/Get/Cancel/Search Documents
- التوقيع الرقمي (Digital Signature)
- حالات الفاتورة: DRAFT, SUBMITTED, VALID, INVALID, REJECTED, CANCELLED
- مزامنة تلقائية كل 5-10 دقائق

## 🛠️ كيفية التشغيل

### 1. تثبيت المتطلبات
```bash
cd /workspace/finovate-ahmed-eg
composer install
```

### 2. إعداد البيئة
```bash
cp .env.example .env
php artisan key:generate
```

### 3. تكوين قاعدة البيانات
```bash
# في ملف .env
DB_CONNECTION=sqlite
# أو
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=finovate
DB_USERNAME=root
DB_PASSWORD=
```

### 4. تشغيل الترحيلات
```bash
php artisan migrate
```

### 5. تشغيل البذور (اختياري)
```bash
php artisan db:seed --class=CompanySeeder
php artisan db:seed --class=UserSeeder
php artisan db:seed --class=ChartOfAccountSeeder
php artisan db:seed --class=GovernmentEntitySeeder
```

### 6. تشغيل السيرفر
```bash
php artisan serve
```

### 7. تشغيل طابور المهام (للخلفية)
```bash
php artisan queue:work
```

### 8. تشغيل المهام المجدولة
```bash
# في crontab
* * * * * cd /workspace/finovate-ahmed-eg && php artisan schedule:run >> /dev/null 2>&1
```
